# Diagram Design References

เอกสารอ้างอิงสำหรับการออกแบบ Diagram
ของระบบบริหารจัดการการยืม-คืนกล้องวงจรปิด
และอุปกรณ์คอมพิวเตอร์

## Diagram ที่จัดทำ

### 1. Context Diagram

แสดงภาพรวมของระบบและผู้เกี่ยวข้องภายนอกระบบ

### 2. DFD Level 1

แสดงกระบวนการหลักของระบบและการไหลของข้อมูล

### 3. DFD Level 2

แสดงรายละเอียดของกระบวนการยืมและคืนอุปกรณ์

### 4. ER Diagram

แสดง Entity และความสัมพันธ์ของข้อมูลในระบบ

### 5. System Flow

แสดงลำดับการทำงานของระบบตั้งแต่การยื่นคำขอยืม
จนถึงการคืนอุปกรณ์

### 6. User Flow

แสดงเส้นทางการใช้งานของผู้ใช้แต่ละบทบาท

### 7. Swimlane Diagram

แสดงกระบวนการทำงานแยกตามบทบาทของผู้ใช้งาน

### 8. Sitemap

แสดงโครงสร้างและลำดับหน้าของเว็บไซต์
