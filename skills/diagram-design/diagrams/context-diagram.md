# Context Diagram
## ระบบบริหารจัดการการยืม-คืนกล้องวงจรปิดและอุปกรณ์คอมพิวเตอร์

### 1. วัตถุประสงค์

Context Diagram แสดงภาพรวมของระบบบริหารจัดการการยืม-คืนกล้องวงจรปิดและอุปกรณ์คอมพิวเตอร์ โดยแสดงผู้เกี่ยวข้องกับระบบ ข้อมูลที่ส่งเข้าสู่ระบบ และข้อมูลที่ระบบส่งกลับไปยังผู้เกี่ยวข้อง

### 2. External Entities

ระบบมีผู้เกี่ยวข้องหลัก 4 บทบาท ได้แก่

1. ผู้ใช้งาน / พนักงาน
2. ผู้จัดการ
3. คลัง / ผู้ดูแลอุปกรณ์
4. ผู้ดูแลระบบ
